# Security Policy

## Reporting a vulnerability

Report security vulnerabilities through GitHub private
vulnerability reporting:

[Report a vulnerability](https://github.com/JSCV-Solutions/nodejs-crypto/security/advisories/new)

Do not open a public issue for a vulnerability. Do not send secrets,
passwords, keys or plaintext exploit payloads outside the private
advisory flow.

## Supported versions

Only the latest minor of the current major line receives security
fixes.

| Version                | Supported |
| ---------------------- | --------- |
| Latest 1.x minor       | yes       |
| Older minors or majors | no        |

Fixes ship as new versions on the supported line. Unsupported lines
do not receive backports.
